# Changelog

## 1.6.0

- The game's own HUD is now hidden by default while NeonHUD shows (configs from 1.5 are switched over once). F8 still brings it back
- The HUD now hides while the pause menu, options or a dialog is open, instead of drawing over them. The game's HUD stays hidden while paused
- Colour, size and effect changes apply instantly without re-linking the game data
- Looking up game types by short name now only searches the game's own code, not other mods' libraries

## 1.5.0

First release on Thunderstore.

- Compact (default) and Full layouts, with separate sizes for the bottom HUD and the player cards
- Mono (default), Neon and Custom themes
- Player cards with an HP threat overlay, a LETHAL warning, a damage ghost and the SP bar
- Frame-exact hitstun release meter, read from the game's own hitstun timer
- Seven-segment ball speed and timer, now playing with a live audio spectrum
- F8 hides the game's own bottom HUD and player panels
